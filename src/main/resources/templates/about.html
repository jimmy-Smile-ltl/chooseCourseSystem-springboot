关于

本项目最初是一份课程设计，现已重写为 Spring Boot + PostgreSQL 版本。

原版技术

JSP + JavaBean + Servlet + JDBC

MySQL 8 + Tomcat 8 + Java 8

项目创建：2021-07-11

重写版技术

Spring Boot 3 + Thymeleaf + Spring Security

PostgreSQL + Flyway

Docker 部署

重写版

  • Spring Boot 3 + Thymeleaf + Spring Security
  • PostgreSQL（Neon），Flyway 管理 schema
  • 选课事务使用行锁、唯一约束和实时容量统计
  • 保留原版登录页视频背景和忘记密码 canvas 粒子特效
  • 部署：Docker → Zeabur / Railway / Render / Fly.io

说明

原版代码和 SQL dump 保留在仓库根目录，重写版位于 server/。

登录页视频和忘记密码背景图来自原项目，仅用于课程演示。
